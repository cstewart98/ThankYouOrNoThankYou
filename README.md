# Thank You Or No Thank You

This is a fun parody of the popular game show "Deal or No Deal" built with ASP.NET.

## Features
- Play the game with randomly generated dogs with tennis balls.
- Deal with the Dog Catcher or risk it all!
- Prizes are random prizes or some have cash values.

## Getting Started
1. Clone this repo.
2. Open in Visual Studio or your preferred IDE.
3. Run the project and have fun!
